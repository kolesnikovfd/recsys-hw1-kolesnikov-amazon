## Постановка

Рекомендуются десять ещё не оценённых пользователем товаров. Положительный интерес — оценка **4 или 5 звёзд**. После очистки 151 254 отзыва, 14 681 пользователь, 8 713 товаров; 120 044 положительных отзыва. Все ранее оценённые товары, в том числе с оценкой 1–3, исключаются из рекомендаций.

Модели реализованы без готовых рекомендательных библиотек:

1. ItemKNN: Jaccard similarity, shrinkage и top-K соседей.
2. iALS: взвешенные чередующиеся least-squares updates.
3. EASE: решение квадратичной задачи с нулевой диагональю.
4. FM: user/item ID, слова из прошлых summary и исторические характеристики товаров.
5. Custom iALS: target, учитывающий величину оценки и её давность.

Дополнительно выполнена абляция FM без метапризнаков. Общий код линейной алгебры и FM адаптирован из [предыдущего проекта](https://github.com/NikkiVeid/recsys-hw1-online-retail); подготовка данных, сходство ItemKNN, target, признаки и эксперименты изменены для Amazon.

## Результаты

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---:|---:|---:|
| Custom iALS | 0.02718 | 0.03988 | 0.073 |
| EASE | 0.02596 | 0.03623 | 0.699 |
| iALS | 0.02305 | 0.03389 | 0.073 |
| ItemKNN | 0.02108 | 0.02962 | 0.864 |
| FM IDs only | 0.01964 | 0.03200 | 0.019 |
| FM | 0.01251 | 0.02040 | 0.058 |

Test: 6,192 пользователей, 8,527 товаров в общем каталоге.

- Custom iALS − iALS: Δ NDCG@10 = +0.00413, 95% CI [+0.00260; +0.00571], положительная разность.
- FM metadata − FM IDs only: Δ NDCG@10 = -0.00713, 95% CI [-0.00927; -0.00515], отрицательная разность.

Ноутбук выполнен целиком без ошибок ячеек; **11 тестов пройдены**. Итоговые средние независимо сверены с метриками каждого пользователя. Подробные выводы — в ноутбуке и [results/conclusions.txt](results/conclusions.txt).

## Протокол

- Train: до 01.07.2013; validation: второе полугодие 2013; test: с 01.01.2014 до конца набора.
- Основная метрика **NDCG@10** определена заранее. Дополнительные — Recall@10 и Coverage@10.
- Все модели используют общих пользователей, полный известный каталог и одинаковую маску ранее оценённых товаров.
- Все настройки выбираются по validation, затем модели заново обучаются на train+validation. Test используется только для итогового сравнения.
- Словарь и характеристики товаров строятся только из отзывов до границы. Кандидаты и признаки фиксируются на начало окна.
- Seed=2026, один поток BLAS/PyTorch, детерминированное разрешение ничьих.
- Собственный target: `(rating - 3) / 2 * (0.5 + 0.5 * exp(-age_days / tau_days))` для оценок ≥4, иначе 0. Confidence и остальные настройки совпадают с выбранным базовым iALS.

## Запуск

Проверено с Python 3.12 на CPU. Для плотных матриц EASE желательно не менее 8 ГБ свободной памяти.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_notebook.py
```

`run_notebook.py` запускает все ячейки текущим Python и сохраняет результаты; глобальная регистрация kernel не нужна. `requirements.txt` содержит прямые зависимости, `requirements-lock.txt` — полную среду проверенного запуска. Системные сборки PyTorch могут отличаться на других платформах.

## Ограничения

5-core изначально сформирован по активности за весь период, поэтому benchmark не моделирует весь Amazon без смещения. Это warm-start оценка пользователей с новым положительным отзывом; cold start и пользователи без такой релевантности не входят в знаменатель. Отзывы не являются логами показов, отсутствие отзыва не равно неприязни. История редактирования текстов и наличие товаров неизвестны. Один split, один seed и ограниченный поиск не гарантируют устойчивость результата. Bootstrap оценивает вариацию пользователей в текущем test-окне, а не изменение качества по времени.
